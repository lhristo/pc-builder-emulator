# Privacy Policy

PC Builder does not sell personal data or upload saved builds. The optional website photo requests are described below.

The app stores saved PC builds locally on the user's device or browser using local storage. Saved builds are not uploaded to a server by this app.

The app does not use analytics, advertising trackers, location services, contacts, photos, microphone, or camera access.

Component names, prices, and compatibility guidance are included for planning. Users should confirm final specifications and prices with the seller or manufacturer before buying parts.

For App Store privacy questions, the expected answer is that this app does not collect data.

## Optional product photos on the website

The browser version can display supplier-hosted product images when the user
selects **Product photo** inside a component inspector. This makes a direct HTTPS
request to the image host, which receives normal connection information such as
the IP address and browser headers. The request does not include saved builds or
an HTTP referrer. This feature is not included in the iOS app. The 3D illustrations
are generated locally and do not require those image requests.
